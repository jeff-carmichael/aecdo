# Use the app

Sheets on the left, contents in the middle, the PDF on the right. Drag the line between two panels to resize them, or double-click it for the default width; the app remembers the sizes.

## Open a drawing set

Open **aecdo** from the Start menu, Applications, or your app menu. The home screen lists the drawing sets in your folder and the ones you used recently. **Open another folder…** (<kbd>o</kbd>) picks a different folder.

Notes and spreadsheets the [AI](assistant.md) writes go in this folder.

A folder can hold several sets. Each `.jsonld` with a PDF of the same name (`house.jsonld` and `house.pdf`) is listed above the sheets under **Drawing sets**, folded to the open one's name. Press <kbd>s</kbd> (or click) to show them, pick one, and press <kbd>Enter</kbd>; <kbd>s</kbd> folds the list again. One set is open at a time. Each set keeps its own [chats](assistant.md#chats), so switching shows that set's past chats.

## Move around

Open a sheet, then a drawing, a layer, an item. What you pick is outlined on the PDF. Press <kbd>?</kbd> for every key.

| Key | Does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move |
| <kbd>Enter</kbd> | Open |
| <kbd>←</kbd> | Back |
| <kbd>/</kbd> | Find a sheet |
| <kbd>s</kbd> | Show or hide the other drawing sets |
| <kbd>z</kbd> / <kbd>f</kbd> | Zoom to selection / fit page |
| <kbd>a</kbd> | Ask the AI |
| <kbd>M</kbd> / <kbd>m</kbd> | Mark up / list markups |
| <kbd>o</kbd> | Open another set |
| <kbd>,</kbd> | Settings |

The mouse works too. Click a box on the PDF to open it.

Links under **Links to other drawings** and **Related** jump to sections, details, and schedules. <kbd>←</kbd> brings you back.

## The PDF

Keep the PDF beside the set with the same name: `plans.pdf` next to `plans.jsonld`. If the app can't find it, pick it from the list in the PDF pane.

## Light and dark

Click the moon or sun at the top right. **Settings → Look** sets it to follow your computer.
